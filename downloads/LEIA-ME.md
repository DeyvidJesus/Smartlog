# SmartLog para Android ARM64

[Baixar ZIP com o APK atualizado](https://github.com/DeyvidJesus/Smartlog/raw/refs/heads/downloads/android-arm64/downloads/SmartLog-Android-arm64.zip)

1. Baixe o ZIP e extraia `smartlog-arm64-atualizado.apk`.
2. Abra o APK em um aparelho Android ARM64 e autorize a instalação pelo navegador/gerenciador de arquivos, se solicitado.

APK compilado a partir do commit `d498f36d55432bfd8fa362adad908d0dbb1c8956`.
Inclui a identidade visual atualizada do app. A API configurada é
`https://smartlog-next-2026.netlify.app/api/v1`.

SHA-256 do APK extraído:
`8b4b4a68b1ebf0385434712dfb20508676de7e6fc67a7d5c11a49cd6666a6907`

O APK mantém a assinatura de debug existente no projeto. Para atualizar uma
instalação anterior, o certificado precisa ser compatível.
